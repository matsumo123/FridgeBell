# FridgeBell🔔

## 📖サービス概要
FridgeBellは、冷蔵庫にある食材を登録して期限切れを防ぐアプリです。  
食材ごとに数量・期限・メモを登録でき、1ページ単位でまとめて管理できます。  
期限が近づいた食材はLINE通知でお知らせし、忙しい毎日でも無駄なく使い切ることができます。
さらに、食材を無駄にせずに過ごした日数に応じてキャラクターが変化する仕組みで、楽しく食品ロス削減に取り組めます。


## 💭このサービスへの思い
冷蔵庫を開けたとき「そういえばこれ買ってた！...もう期限切れだ」と捨ててしまうことが何度もありました。そのたびに無駄にしてしまったことを悔やんでいました。
友人に話すと「分かる！この前も○○捨てちゃった...」と共感を得ることも多かったです。
こうした「うっかり忘れて食材を無駄にする」悩みを減らしたい。
その思いから、期限を事前に知らせてくれるアプリを作ろうと考えました。

## 👨‍👩‍👧‍👦ユーザー層
- 日々の食材管理を効率化したい主婦・主夫
- 冷蔵庫の中を把握して無駄なく料理したい方
- まとめ買い・作り置きをする方
- 食品ロスを減らしたいと考えている方

## 📋主な機能
- 食材登録
  - デフォルト食材とユーザー追加食材から選択
  - 食材ごとに数量・期限・メモを入力
  - ボタンクリックで数量をカウント
  - 登録は1ページ単位（1ページ内ならまとめて登録可能）
- 食材リスト追加
  - デフォルト食材リストにない食材を自由に追加
- 食材一覧
  - 期限が短い順に表示
  - 期限ごとに色分けラベル(グレー・赤・黄・緑)で分かりやすく表示
- 消費・廃棄登録
  - 「食べた」「捨てた」ボタンで登録
  - チェックボックス式で複数食材をまとめて処理
  - 連続廃棄ゼロ日数を記録
- リマインド(準備中)
  - 設定した時間に期限が短い食材をLINE通知

## 💟推しポイント
- ユーザーの負担軽減
食材はリストから選ぶだけ。期限も初期値が設定されているので、手入力の手間を大幅に削減できます。  
- 期限が切れる前にお知らせ（準備中）
LINE通知で期限間近の食品をお知らせ。忙しい毎日でも「うっかり忘れ」を防ぎます。
- 食品一覧の色分け
食品一覧は残り日数に応じてラベルの色が変更。期限が迫った食材をすぐに把握できます。  
  | 色 | 状態 |
  |----|------|
  | グレー | 期限切れ |
  | 赤 | 残り2日以内 |
  | 黄 | 残り5日以内 |
  | 緑 | 6日以上 |

## ⚒️使用技術

- バックエンド：Rails7.2.2 , Ruby3.3.6
- データベース：PostgreSQL
- 開発環境：Docker
- インフラ：Fly.io
- 画像保存: Active Storage + AWS S3
- 認証：Devise, omniauth-line(予定)
- API:LINE Messaging API(予定)
